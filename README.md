# Actividad Git y GitHub

Este proyecto hace parte de una actividad académica para practicar el uso de Git, GitHub y el flujo de trabajo con ramas y Pull Requests.

## Contenido

- `index.html`: Página principal con una breve presentación.
- `servicios.html`: Página con una lista de servicios.
- `contacto.html`: Página con información de contacto.

## Tecnologías utilizadas

- HTML5
- Git
- GitHub
